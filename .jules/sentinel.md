## 2024-07-03 - Hardcoded XML-RPC Bypass Token in Nginx Configuration
**Vulnerability:** A hardcoded token (`$arg_token = "xrpc-9f8e7d6c5b4a"`) was found in `server-php/config/conf.d/wordpress.conf` allowing a bypass to the otherwise blocked XML-RPC endpoint (`/xmlrpc.php`). This creates a significant security risk, as anyone possessing the hardcoded token can interact with the XML-RPC endpoint, potentially launching brute-force attacks or exploiting vulnerabilities in XML-RPC.
**Learning:** Hardcoding secrets directly into source code or configuration files meant for version control is a critical anti-pattern. This bypass mechanism was likely added for debugging or internal tooling but left the endpoint exposed without robust authentication. Nginx configurations lack environment variable substitution at runtime in this setup.
**Prevention:** Remove the hardcoded token bypass completely. The XML-RPC endpoint should be unconditionally blocked (`deny all;`) if it's not strictly required. If access is needed, use proper upstream authentication mechanisms, rather than a single shared token.
