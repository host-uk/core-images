## 2024-04-30 - [Hardcoded Secret Bypass in Nginx config]
**Vulnerability:** A hardcoded token `xrpc-9f8e7d6c5b4a` was found in `server-php/config/conf.d/wordpress.conf` allowing a bypass to the default block on `/xmlrpc.php`. This acts as a backdoor if the token is discovered, allowing unauthorized access to the XML-RPC endpoint.
**Learning:** Hardcoded secrets in infrastructure configuration (like Nginx) create severe security vulnerabilities as they cannot be rotated easily and are exposed to anyone who can view the repository or the deployed configuration file. An attacker can use this token to bypass the intended security control.
**Prevention:** Never hardcode secrets in configuration files. If an endpoint requires an exception to be accessed, implement a proper, secure, and authenticated mechanism (e.g., using secure tokens managed outside of the repository, proper IP allowlisting, or upstream authentication services) rather than a simple string match against query parameters in Nginx.
