## 2024-05-06 - [CRITICAL] Nginx XML-RPC Hardcoded Secret Bypass
**Vulnerability:** A hardcoded token (`xrpc-9f8e7d6c5b4a`) in `server-php/config/conf.d/wordpress.conf` was used to conditionally bypass an otherwise blocked `/xmlrpc.php` endpoint. This acts as a backdoor allowing potential brute-force and DDoS attacks against the WordPress instance by anyone with access to the codebase or the token.
**Learning:** Security controls based on string comparisons in web server configurations (like Nginx's `if ($arg_token = "...")`) are highly prone to hardcoding and leakage. Hardcoded secrets bypass intended security policies and create persistent backdoors.
**Prevention:** Strictly prohibit hardcoded credentials in configuration files. If conditional access is required, rely on established upstream authentication mechanisms, environment variable substitution (if securely managed), or restrict access by trusted IP addresses, rather than inline shared secrets. Endpoints like `xmlrpc.php`, which are largely deprecated, should be unconditionally blocked (`deny all;`).
