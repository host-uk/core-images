## 2025-04-09 - [Hardcoded Secret in Nginx Config for XML-RPC]
**Vulnerability:** A hardcoded token `xrpc-9f8e7d6c5b4a` was discovered in the Nginx configuration `server-php/config/conf.d/wordpress.conf` to conditionally bypass the block on `/xmlrpc.php`. This allows anyone with the token to access the potentially vulnerable XML-RPC endpoint, facilitating brute force or DDoS attacks against the WordPress instance.
**Learning:** Hardcoded secrets in infrastructure configuration files like Nginx are particularly dangerous as they bypass application-layer security and are easily exposed through source control. The intent might have been to allow internal or administrative access, but embedding the secret directly in the repository is a flawed approach. Additionally, exposing such an endpoint, even via a secret, expands the attack surface needlessly for a feature that is widely deprecated.
**Prevention:** Do not hardcode secrets in configuration files. If an endpoint is known to be risky (like `/xmlrpc.php`), the safest practice is to completely deny access (`deny all;`) unless absolutely required. If required, utilize standard IP whitelisting or robust upstream authentication mechanisms instead of simple query parameter checks.
