## 2024-04-23 - [Hardcoded Secret in Nginx Configuration]
**Vulnerability:** A hardcoded token (`$arg_token = "xrpc-9f8e7d6c5b4a"`) was used directly in the Nginx configuration file (`wordpress.conf`) to conditionally bypass a block on the `/xmlrpc.php` endpoint. This exposes a static secret in version control that grants access to a known high-risk WordPress endpoint.
**Learning:** Configurations often use variables from requests (like `$arg_token`) for simple authentication mechanisms. However, hardcoding the expected secret directly in the configuration file bypasses environment variable injection mechanisms (especially if tools like `envsubst` are not used or bypassed, as is the case in `server-php/scripts/entrypoint.sh`).
**Prevention:** Avoid using hardcoded secrets in web server configuration files. If conditional access is required, rely on robust upstream authentication, standard basic authentication with hashed passwords, or ensure secrets are strictly injected at runtime from secure environment variables. For known risky endpoints like `/xmlrpc.php`, the safest default is unconditional blocking (`deny all;`).
