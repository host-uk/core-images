## 2024-05-21 - [CRITICAL] Hardcoded secret in Nginx configuration
**Vulnerability:** A hardcoded token (`xrpc-9f8e7d6c5b4a`) was found in `server-php/config/conf.d/wordpress.conf` which could be used to bypass the XML-RPC block and access the WordPress XML-RPC endpoint (`/xmlrpc.php?token=xrpc-9f8e7d6c5b4a`).
**Learning:** Hardcoded secrets in configuration files can be easily discovered by anyone with read access to the source code, creating a backdoor and exposing the application to potential abuse (e.g., brute-force attacks via XML-RPC).
**Prevention:** Never hardcode secrets or access tokens directly into source code or configuration files. If an endpoint needs to be restricted, use established authentication mechanisms or unconditionally block access (`deny all;`) if it's not needed. If a token is required, it must be provided securely at runtime (e.g., via environment variables or a secure key management system), although Nginx `$arg_token` checks are generally not recommended for robust security.
