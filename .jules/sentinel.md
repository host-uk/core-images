## 2024-05-18 - [CRITICAL] Hardcoded Secret for XML-RPC Bypass
**Vulnerability:** A hardcoded authentication token (`xrpc-9f8e7d6c5b4a`) was found directly in the Nginx configuration file (`server-php/config/conf.d/wordpress.conf`) to bypass the XML-RPC block, allowing requests passing this token in the query string (e.g., `?token=xrpc-9f8e7d6c5b4a`).
**Learning:** Storing secrets like authentication tokens in configuration files (especially those checked into version control) is a critical security vulnerability. Furthermore, using `$arg_token` checks in Nginx configurations is an insecure way to manage authentication, especially for an endpoint that is frequently targeted like `/xmlrpc.php`. The logic also skipped `$is_args` and similar handling.
**Prevention:** Unconditionally block XML-RPC (`deny all;`) in WordPress environments unless explicitly required. If required, use proper external authentication mechanisms (like Basic Auth, or better yet, API tokens managed by the application logic and not hardcoded into Nginx). Never store plaintext secrets or tokens in Nginx configurations.
