## 2024-05-24 - [Hardcoded Secret Bypass in Nginx Config]
**Vulnerability:** A hardcoded token (`$arg_token = "xrpc-9f8e7d6c5b4a"`) was found in the Nginx configuration file (`server-php/config/conf.d/wordpress.conf`) for WordPress. This allowed bypassing the block on the `/xmlrpc.php` endpoint.
**Learning:** Using hardcoded secrets or tokens within Nginx configuration files to bypass security blocks is an anti-pattern. These configurations are often checked into version control, leading to the exposure of the secret. Furthermore, Nginx configuration files are not the appropriate place for handling authentication or authorization logic.
**Prevention:** Always block known vulnerable or unnecessary endpoints (like `/xmlrpc.php`) unconditionally (e.g., using `deny all;`). If access is genuinely required, use proper authentication mechanisms at the application level or via established Nginx auth modules, and never hardcode secrets in configuration files. Secrets should be managed through environment variables or dedicated secret management systems.
