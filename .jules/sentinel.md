## 2025-02-14 - [Hardcoded Bypass Tokens in Infrastructure Config]
**Vulnerability:** Found a hardcoded authentication token (`xrpc-9f8e7d6c5b4a`) embedded directly in the Nginx configuration file (`server-php/config/conf.d/wordpress.conf`) designed to allow conditional bypass of the XML-RPC endpoint block.
**Learning:** Hardcoded bypass mechanisms within infrastructure config files (like Nginx confs) pose a critical risk because these files are committed to version control and distributed to all team members. Secrets must not be managed at the infrastructure layer without proper secret-injection mechanisms, and endpoints like XML-RPC should rely on robust plugin-level authentication or strict network isolation rather than static keys.
**Prevention:** Unconditionally block the endpoint at the infrastructure level (`deny all;`). If legitimate access is needed, use standard authentication mechanisms within the application code or inject secrets securely via environment variables and templating (`envsubst`) rather than static strings.
