## 2024-03-12 - [CRITICAL] Hardcoded Secret in Nginx Config
**Vulnerability:** A hardcoded token (`$arg_token = "xrpc-9f8e7d6c5b4a"`) was discovered in `server-php/config/conf.d/wordpress.conf`. It was being used as an authentication bypass mechanism to allow access to the otherwise blocked `/xmlrpc.php` endpoint.
**Learning:** Hardcoding secrets directly into configuration files completely negates the security benefits of blocking sensitive endpoints. Because the `server-php` entrypoint uses the raw configuration (it skips `envsubst` as per repository memory), runtime environment variables could not be used to securely inject a token, leading to the dangerous practice of hardcoding the secret in source control.
**Prevention:** Hardcoded secrets in Nginx configuration files (e.g., `$arg_token` checks) are strictly prohibited. Sensitive endpoints like XML-RPC should be unconditionally blocked (`deny all;`) if not strictly necessary, or protected via proper upstream authentication mechanisms rather than URL parameters. Never commit secrets to source control.
