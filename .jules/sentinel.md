## 2024-06-13 - [Hardcoded Secret Bypass in XML-RPC]
**Vulnerability:** A hardcoded secret (`$arg_token = "xrpc-9f8e7d6c5b4a"`) was present in the Nginx configuration `server-php/config/conf.d/wordpress.conf` to allow bypassing the XML-RPC block (`/xmlrpc.php`). This creates a backdoor that can be discovered and exploited if the codebase or configuration is exposed, allowing unauthenticated access to the XML-RPC endpoint, which is known for various vulnerabilities (e.g., brute force, DDoS).
**Learning:** Hardcoded secrets in configurations provide a false sense of security and pose a severe risk if exposed. They violate the principle of keeping secrets separate from the source code and configuration files. It highlights a common anti-pattern where developers add temporary or undocumented backdoors for convenience or integration that are left in production environments.
**Prevention:** Unconditionally block known dangerous endpoints like `/xmlrpc.php` in Nginx using `deny all;`. If access is legitimately required, implement proper authentication using standard mechanisms (e.g., standard HTTP authentication or application-level tokens) rather than hardcoding static tokens in web server configurations. Security tools should scan configuration files for hardcoded secrets or backdoor-like patterns.
