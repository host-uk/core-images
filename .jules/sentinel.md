## 2024-05-30 - Hardcoded XML-RPC Bypass Token
**Vulnerability:** A hardcoded token (`xrpc-9f8e7d6c5b4a`) was found in the Nginx configuration (`server-php/config/conf.d/wordpress.conf`) to bypass the XML-RPC block. This exposes the secret in version control and allows anyone who discovers it to access the restricted endpoint.
**Learning:** Hardcoded secrets in infrastructure configuration files (like Nginx) represent a significant security risk, as these files are often widely distributed in container images and easily readable. Using a single static token for access control is a weak authentication mechanism.
**Prevention:** Never hardcode secrets in configuration files. If an endpoint like `/xmlrpc.php` needs to be disabled for security reasons, it should be unconditionally blocked (`deny all;`). If legitimate access is required, it should be authenticated properly through application logic or managed identity providers, rather than static tokens evaluated at the proxy layer.
