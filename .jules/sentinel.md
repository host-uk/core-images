## 2024-04-21 - [Hardcoded Secret in Nginx Config via Query Parameter]
**Vulnerability:** A hardcoded secret token (`xrpc-9f8e7d6c5b4a`) was found in the Nginx configuration file `server-php/config/conf.d/wordpress.conf` used to bypass the block on `/xmlrpc.php` via a query argument check (`$arg_token`).
**Learning:** Checking query parameters directly in Nginx configurations with hardcoded values is an anti-pattern. While it provides a quick bypass for tools or internal access, committing secrets directly to configuration files exposes them in version control and risks deployment of compromised configurations. It's difficult to rotate these secrets, and they are inherently vulnerable to source code disclosure.
**Prevention:** Unconditionally block sensitive endpoints if they are not needed. If access is genuinely required, use proper authentication mechanisms (e.g., HTTP Basic Auth integrated with a secure credential store, mutual TLS) or utilize network-level access controls (e.g., restricting access to specific IP ranges or internal VPCs) rather than embedding secrets in proxy configuration files.
