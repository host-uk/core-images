## 2026-05-28 - [CRITICAL] Fix hardcoded XML-RPC bypass secret
**Vulnerability:** A hardcoded token `xrpc-9f8e7d6c5b4a` was discovered in `server-php/config/conf.d/wordpress.conf` acting as a bypass for accessing `/xmlrpc.php`. This allows an attacker who finds the source code or discovers this token to access XML-RPC, potentially performing brute force or pingback attacks.
**Learning:** Hardcoding secrets directly in Nginx configurations as token checks should be avoided. Any authentication logic should not depend on static plaintext tokens inside infrastructure code, particularly for sensitive or deprecated endpoints like `/xmlrpc.php`.
**Prevention:** Unconditionally block unused/sensitive endpoints like `/xmlrpc.php` in the Nginx configuration. Do not build custom token bypass logic within the web server config. Ensure secrets, if necessary, are passed dynamically and stored securely, typically verified by the application code and not directly in Nginx configuration files via `if ($arg_token = "...")`.
