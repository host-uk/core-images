## 2024-05-18 - [Hardcoded Secret Bypass in Nginx Configuration]
**Vulnerability:** A hardcoded token (`xrpc-9f8e7d6c5b4a`) was found in the `server-php/config/conf.d/wordpress.conf` Nginx configuration for the `location = /xmlrpc.php` block. This allowed a remote attacker to bypass the block and access the XML-RPC endpoint via the query parameter `?token=xrpc-9f8e7d6c5b4a`.
**Learning:** Hardcoded secrets in infrastructure configuration files (like Nginx) create a critical security vulnerability. When configurations are committed to repositories, any secrets they contain become accessible. The previous setup attempted "security by obscurity" by using a token to allow access to an otherwise restricted endpoint, but since the token was hardcoded, it bypassed the very protection it was intended to enforce.
**Prevention:** Hardcoded secrets (e.g., `$arg_token` checks) are strictly prohibited in Nginx configuration files. Required endpoints must use proper authentication mechanisms or be unconditionally blocked (e.g., using `deny all;`).
