## 2024-05-02 - [CRITICAL] Fix hardcoded XML-RPC secret bypass
**Vulnerability:** A hardcoded token (`xrpc-9f8e7d6c5b4a`) was present in `server-php/config/conf.d/wordpress.conf` acting as a secret to bypass the default block on `/xmlrpc.php`. This allows anyone with the token to access the potentially vulnerable XML-RPC endpoint of WordPress, which is susceptible to brute-force and DDoS attacks.
**Learning:** Hardcoded secrets in Nginx configurations can be introduced when environment variable substitution (`envsubst`) is bypassed at runtime (e.g., in `server-php/scripts/entrypoint.sh`), leading developers to commit secrets directly into the configuration files to make them work.
**Prevention:** Always use unconditional blocks (`deny all;`) for dangerous endpoints unless access is strictly required and authenticated via secure upstream mechanisms. Do not hardcode secrets in source code or configuration files. If conditional access is needed, rely on proper server-side authentication rather than single, shared tokens.
